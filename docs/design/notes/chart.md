# Chart decisions

- Package only deployment templates, defaults, validation, generated RBAC and native alert rules; examples and tests live in `hack/chart`.
- Ignore agent state, archives, Markdown and former fixture directories; compare the packaged archive with an exact allowlist.
- Require installer-selected repository, hub identity, install endpoint and Temporal address; the image tag defaults to Chart.appVersion.
- Resource names derive from the release name; cluster RBAC names must be unique across namespaces.
- Fix the Deployment at one replica with maxSurge 0/maxUnavailable 1, accepting rollout downtime.
- Keep runAsNonRoot and RuntimeDefault seccomp, a read-only root filesystem, no privilege escalation and ALL capabilities dropped. OpenShift assigns the UID, so do not pin runAsUser/runAsGroup; the image uses numeric USER 65532.
- Mount config as a directory without subPath so Kubernetes updates reach the live watcher.
- Hash only startup-bound config, including stuckAfter captured by main; pool and live timing edits must not restart the pod. Chart labels and the checksum take precedence over user additions.
- Preserve all controller defaults and strict config validation. The default buffer is 10 percent with a floor of two; maxSlots remains 100. Pools opt in by name and all example pools start in dry run.
- Go validates duration positivity and timing relationships; schema checks syntax, types and ranges. Invalid hub/default config rejects the document; invalid merged pool timing blocks that pool.
- Keep Temporal CA Secret support for Route connections; use generic args, env, volumes and mounts for other credentials and certificates. Secret content rotation alone does not roll pods.
- Secrets remain external. Mount CA files read-only with mode 0444 so namespace-assigned UIDs can read them.
- Metrics use authenticated HTTPS. ServiceMonitor and PrometheusRule are independent opt-ins requiring externally installed Prometheus Operator CRDs; rendering never depends on API discovery.
- Merge raw ServiceMonitor endpoint fields over endpoint defaults so Prometheus authentication and TLS settings pass through without chart-specific models.
- Generate manager permissions from controller markers: read Agents/InfraEnvs/NodePools and patch InfraEnvs. Separate roles cover leader-election leases/events, metrics authentication reviews and GET /metrics; bind readers only when subjects exist.
- External RBAC must provide all permissions when rbac.create is false. Namespace security policy and network restrictions belong to site configuration.
- Create no Namespace, Secret, CRD, webhook, hook or PDB. Uninstall preserves external Secrets and the namespace; rollback restores release values/config with the workload but cannot reclaim added capacity.
- Check RBAC drift by comparing generated bytes without git or overwriting the shipped file.
- CI cancels superseded branch/PR runs; chart drift generation requires Go. Helm and promtool downloads retain upstream SHA256 verification.
- Exclude the controller envtest suite from unit tests; integration tests require a dedicated environment.
- Alert on absent controller metrics because pool comparisons alone cannot detect a missing controller; intentionally paused or self-blocked pools are not incidents.
